
# Calculating Distance Formula

## Description
-this is a python program that calculates the between the two points on a 2D coordinate plane, It uses distance formula and pythons math library, specifically pow() and sqrt()

## How to Run
```markdown
1st Make sure python is installed in you computer,
2nd Open the python file in an editor such as visual code,
3rd Run the program,
4th Enter the x and y coordinates when prompt,
5th The program will display the distance between the two points.
```

## Input Needed
```markdown
x1 - x coordinate of the first point
y1 - y coordinate of the first point
x2 - x coordinate of the second point
y2 - y coordinate of the second point
```

## Sample Output
```markdown
Enter x1 = 2
Enter y1 = 3
Enter y2 = 6
Enter y2 = 6
The distance between the two points is 5.05
```
